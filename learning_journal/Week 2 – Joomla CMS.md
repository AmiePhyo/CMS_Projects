## Content Insights

The biggest lesson I learned this week was that Joomla organises a website very differently from a static website. I also realized that separating content (articles) from presentation (templates) makes it easier to redesign a website without rewriting the content, which improves maintainability and scalability. Instead of creating individual HTML pages, Joomla stores content as articles and displays them through menus, modules, and templates. I realized that understanding the relationship between these components is essential because changing one component alone does not always change what appears on the website.

I also learned how the Cassiopeia template controls the overall appearance of the website while allowing developers to customize colours, layout, typography, and module positions without changing the website content. This helped me understand the separation between presentation and content, making websites easier to maintain and update.

Another important concept I learned was how Joomla extensions increase functionality without requiring developers to build every feature themselves. I used Convert Forms to create contact and internship matching forms, which demonstrated how extensions can quickly add professional features while remaining integrated with the CMS. I also explored Akeeba Backup and learned why creating complete website backups is an important part of website maintenance before making major changes or deploying a website.

Overall, this practical helped me understand that a CMS is more than a website builder. It provides a structured system for managing content, users, templates, and extensions while storing everything in a database that dynamically generates web pages.

## Career / Employability / Learning Insights

Before this practical, I assumed Joomla would be very similar to WordPress because both are content management systems. However, I found Joomla required a deeper understanding of how articles, menus, modules, and templates interact before I could successfully build my website. Although this made the learning process slower at first, I found that I understood the overall architecture of CMS platforms much better after working through these concepts.

While researching Joomla, I noticed that WordPress appears in more job advertisements, particularly for freelance and agency web development roles. However, Joomla is still used by organisations that require more structured content management and flexible user permissions. Learning Joomla has therefore expanded my understanding of CMS development rather than limiting me to only one platform, which I believe will make it easier to adapt to different content management systems in the future.

I also reflected on my own learning strategy this week. I found that reading a small section of the documentation and immediately applying it to my InternPilot website was much more effective than watching long tutorial videos from beginning to end. Building the website while referring back to the documentation helped me remember the concepts more clearly because I was solving real problems instead of simply following instructions. I plan to continue using this approach throughout the remaining practicals because it improves both my confidence and my ability to work independently.
