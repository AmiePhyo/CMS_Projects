# Practical 6 – Group Setup

# Objective

The objective of this practical was to set up the collaboration tools required for our group project. This included joining the team's communication platform, setting up the GitHub repository, planning the project, and agreeing on how we would work together throughout the semester.

---

# Learning Activities

## Team Communication

Our team uses **Discord** as our primary communication platform. We use it to discuss project ideas, assign tasks, share updates, ask questions, and organise meetings.

Using Discord allows us to communicate quickly and keep everyone informed throughout the project.

---

## GitHub Repository

I joined our team's GitHub repository and cloned it to my local computer using Visual Studio Code.

During this practical, I:

- Cloned the repository to my local machine.
- Opened the project in Visual Studio Code.
- Pulled the latest changes from GitHub.
- Made commits and pushed my updates to the repository.
- Collaborated with my teammates by keeping the repository up to date.

Using GitHub helped me understand collaborative development and version control. It also made it easier for our team to work on the same project without losing each other's changes.

---

## Project Planning

Our group discussed different project ideas before deciding to develop an **Online Coffee Shop** website using WordPress.

We planned:

- Website pages and structure
- Features to include
- Team member responsibilities
- Development workflow
- Timeline for completing the project

We organised our tasks using our project management board so that everyone clearly understood their responsibilities.

---

## Group Agreement

Our team completed the group agreement by discussing expectations for communication, teamwork, and task management.

We agreed to:

- Communicate regularly through Discord.
- Complete assigned tasks before deadlines.
- Inform the team if any delays or issues arise.
- Respect each other's opinions during discussions.
- Help each other when solving technical problems.

This agreement helped establish clear expectations for the project.

---

## LinkedIn

I connected with my teammates on LinkedIn to build my professional network and prepare for the final project documentation.

---

# What I Learned

This practical showed me that successful software development depends on both technical skills and effective teamwork.

I became more familiar with using GitHub for collaborative development, including cloning repositories, pulling updates, committing changes, and pushing work to a shared repository.

I also learned that communication tools such as Discord and project management boards play an important role in organising tasks, tracking progress, and ensuring everyone stays informed throughout the project.

Planning the project before development begins helps the team work more efficiently and reduces confusion later.

---

# Challenges

At the beginning, I was still becoming familiar with our team's workflow and GitHub collaboration. By communicating with my teammates through Discord and regularly checking project updates, I became more confident working within a shared development environment.

---

# Reflection

This practical helped me understand the importance of setting up collaboration tools before starting development. Having clear communication, version control, and project planning from the beginning provides a strong foundation for teamwork.

Moving forward, I will continue contributing to the GitHub repository, communicating regularly with my teammates on Discord, and completing my assigned tasks according to our project plan.
