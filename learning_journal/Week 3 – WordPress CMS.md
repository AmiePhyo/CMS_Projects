## Content Insights

The biggest lesson I learned this week was that WordPress allows developers to build feature-rich websites by combining themes, plugins, and built-in content management tools. I also realized that separating website functionality into plugins makes a website easier to maintain because each plugin performs a specific task without requiring changes to the core WordPress files.

Instead of manually coding every feature, I used plugins such as WPForms to create forms, Content Views to display internship listings, Search & Filter to organise internship posts, and WPCode to safely add custom HTML, CSS, JavaScript, and PHP snippets. This helped me understand how WordPress encourages reusable and modular website development.

I also learned that WordPress stores pages, posts, categories, tags, and plugin data inside a database rather than individual HTML files. This allows website content to be updated through the dashboard while WordPress dynamically generates the web pages for visitors. Understanding this architecture helped me appreciate why WordPress is widely used for websites that require frequent content updates.

Overall, this practical showed me that WordPress is not simply a website builder. It is a flexible content management system that allows developers to combine themes, plugins, and databases to create scalable and maintainable websites.

## Career / Employability / Learning Insights

Compared with Joomla, I found WordPress much easier to learn because its interface is more intuitive and there are many plugins available to extend website functionality. Although plugins make development faster, I also realized that developers still need to understand how each plugin works and how different plugins interact to avoid compatibility or performance issues.

While researching WordPress, I found that it remains one of the most requested CMS skills in web development job advertisements, particularly for freelance developers, digital agencies, and small to medium-sized businesses. Many positions also expect developers to understand HTML, CSS, JavaScript, PHP, and MySQL alongside WordPress, showing that CMS knowledge alone is not enough for professional web development.

This week also helped me improve my learning strategy. Instead of trying to memorise every WordPress feature, I focused on understanding the purpose of each plugin before applying it to my InternPilot website. I found that experimenting with the plugins and referring back to the official documentation whenever I encountered problems helped me understand the concepts much better than simply following tutorial videos. Going forward, I plan to continue learning by combining documentation, practical implementation, and experimentation because this approach has been the most effective for me.
